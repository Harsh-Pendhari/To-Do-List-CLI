# 📝 To-Do List CLI (Multi-User)

A fully featured **multi-user** command-line To-Do List manager built in Python.  
Store your lists and tasks persistently in JSON, manage deadlines, and enjoy a polished colored terminal interface.

---

## ✨ Features

- **Multiple Users** — Create, switch, and delete users easily  
- **Unlimited Lists per User** — Organize tasks into separate lists  
- **Unlimited Tasks per List** — Keep track of as many tasks as you want  
- **Optional Deadlines** for each task  
- **Edit, Rename, and Delete** tasks or lists  
- **Colorized Interface** with typewriter-style effects  
- **Persistent Storage** using JSON (no database needed)  
- **Interactive Menus** for easy navigation

## 🚀 Installation & Usage

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Harsh-Pendhari/To-Do-List-CLI.git

cd To-Do-List-CLI
```
### 2️⃣ Install Dependencies

This project requires only colorama and tabulate in addition to Python's standard libraries.

``` bash
pip install colorama tabulate
```

### 3️⃣ Run the App
```bash
python TO-DO-LIST.py
```
